# pandoc-simple 

A pandoc-based single-page Markdown site with no SSG toolchain.

## Build

```bash
pandoc index.md -o index.html --template=html.template.pandoc --standalone -f gfm
```

## Templates

Uses Pandoc [templates](https://pandoc.org/demo/example33/6-templates.html#templates)

Probably works with [pandoc-templates.org](https://pandoc-templates.org/)



## Deploy

Push to `main` - GitHub Actions handles the rest (~20s total).
